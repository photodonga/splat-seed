- Inkipedia의 게임 이미지 파일들은 **저작권 보호 대상(공정 이용을 근거로 위키에 게시)**으로 표시되어 있습니다. 위키 게시 또는 출처 표시 자체가 다른 사이트에서의 재사용 허가를 주는 것은 아닙니다.
- 이번 변경은 이미지를 저장소에 복사하지 않고 원본 이미지 CDN URL을 이용하는 디자인 실험입니다. 외부 링크 제한이나 이미지 삭제 시 CSS 자체 아이콘이 보이도록 했습니다.
- Nintendo 또는 Inkipedia의 공식 제휴·인증을 받은 서비스가 아닙니다.
- 실제 공개 운영 전에 이미지 사용 적정성, 권리자 정책, 핫링크 허용 여부를 추가 검토해야 합니다.
